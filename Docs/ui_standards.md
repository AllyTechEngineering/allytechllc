## Cards

Cards should appear visually elevated from the page background.

Default behavior:

- Use Material 3 `Card`
- Default elevation: approximately `4`
- Rounded corners: approximately `16 px`
- Entire card should be clickable when it represents navigation
- Use `InkWell` for Material interaction feedback
- Increase elevation slightly on hover for desktop/web
- Do not bake shadows or rounded corners into image assets

Recommended hover behavior:

- Default elevation: `4`
- Hover elevation: approximately `8`
- Keep animation subtle and fast
- Do not significantly change card size or layout on hover
