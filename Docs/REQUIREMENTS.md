# AllyTech LLC Website Requirements

## 1. Purpose

### REQ-1 Public Website

-   REQ-1.1 The system shall provide a public-facing website for
    AllyTech LLC.
-   REQ-1.2 The system shall present AllyTech LLC engineering services.
-   REQ-1.3 The system shall present representative engineering
    projects.
-   REQ-1.4 The system shall support mobile, tablet, laptop, and desktop
    browser use.

## 2. Services

### REQ-2 Service Content

-   REQ-2.1 The system shall present IoT App Development.
-   REQ-2.2 The system shall present IoT Web Development.
-   REQ-2.3 The system shall present Embedded IoT Development.
-   REQ-2.4 The system shall present Schematic & PCB Design.
-   REQ-2.5 The system shall present IoT NPD Project Management.
-   REQ-2.6 Each service shall support a summary view and a detail view.
-   REQ-2.7 Service detail content shall support ordered image-and-text
    sections.

## 3. Projects

### REQ-3 Project Content

-   REQ-3.1 The system shall present representative AllyTech LLC project
    work.
-   REQ-3.2 The system shall include the Proofing Ovens project.
-   REQ-3.3 The system shall include the Flutter/Dart Embedded Linux
    project.
-   REQ-3.4 The system shall include the IoT Connected RFID project.
-   REQ-3.5 The system shall include the Sailing Race Computer project.
-   REQ-3.6 Each project shall support a summary view and a detail view.
-   REQ-3.7 Project detail content shall support ordered image-and-text
    sections when required.

## 4. Navigation

### REQ-4 Site Navigation

-   REQ-4.1 The system shall provide navigation to the major website
    sections.
-   REQ-4.2 Major pages shall be browser-addressable by URL.
-   REQ-4.3 Individual service pages shall be browser-addressable by
    URL.
-   REQ-4.4 Individual project pages shall be browser-addressable by
    URL.
-   REQ-4.5 Browser navigation shall remain functional when the
    responsive layout changes.

## 5. Responsive User Interface

### REQ-5 Responsive Layout

-   REQ-5.1 The system shall adapt its layout according to available
    display width.
-   REQ-5.2 Mobile layouts shall use a compact navigation interface and
    primarily single-column content.
-   REQ-5.3 Tablet layouts shall support expanded navigation and
    multi-column content where appropriate.
-   REQ-5.4 Desktop layouts shall support expanded navigation,
    multi-column content, and readable content-width constraints.
-   REQ-5.5 Images and content shall scale within the available display
    area.

## 6. Content Presentation

### REQ-6 Reusable Content

-   REQ-6.1 Service and project content shall use a consistent
    presentation structure.
-   REQ-6.2 Content changes shall not require separate page-layout
    implementations for each service or project.
-   REQ-6.3 Service and project detail pages shall support a primary
    image, descriptive text, and optional detail sections.

## 7. Visual Design

### REQ-7 User Interface Consistency

-   REQ-7.1 The system shall use a consistent visual theme across the
    website.
-   REQ-7.2 Shared navigation, cards, detail sections, typography, and
    page structure shall remain visually consistent across supported
    display sizes.

## 8. Web Application

### REQ-8 Progressive Web Application

-   REQ-8.1 The website shall operate as a Flutter web application.
-   REQ-8.2 The website shall support Progressive Web App behavior in
    supported browsers.
-   REQ-8.3 The production website shall be available through the
    AllyTech LLC domain.
